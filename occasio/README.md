# Occasio

Content intelligence for the site's posts from Occasio, built on its Google Analytics and Search Console data.

Connects through Occasio's own hosted MCP server at `https://occasio.digital/mcp`.
Connecting opens Occasio's sign-in; the bots app registers itself with Occasio on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to occasio.digital.

## Read only

Research and reporting only; nothing in Occasio changes.
