name: allspice-analytics
description: Answer traffic and revenue questions from the Allspice Analytics tools.
---

Use the Allspice Analytics tools for any question about the site's traffic,
top posts, or revenue. Ground every number in a tool result from this
conversation — never estimate or reuse numbers from memory.

- Date ranges: default to the last 7 full days when the user names none, and
  say the range you used.
- Lead with the finding, not the table: one sentence on what changed, then the
  numbers that back it.
- Reports follow promote / fix / refresh: what to promote while it's hot, what
  underperforms and why, what old post is worth refreshing.
- If the tools are not connected or return an authorization error, say so and
  point the owner at the Allspice Analytics integration — never guess.
