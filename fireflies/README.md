# Fireflies

Meeting transcripts, summaries and action items from Fireflies.

Connects through Fireflies's own hosted MCP server at `https://api.fireflies.ai/mcp`.
Connecting opens Fireflies's sign-in; the bots app registers itself with Fireflies on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to api.fireflies.ai.

## Read only

Research and reporting only; nothing in Fireflies changes.
