# Upwork

Find and hire freelancers on Upwork, such as photographers, editors or VAs.

Connects through Upwork's own hosted MCP server at `https://mcp.upwork.com/mcp`.
Connecting opens Upwork's sign-in; the bots app registers itself with Upwork on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to mcp.upwork.com.

## Writes

This connector can change things in Upwork. Keep the workspace's approval mode on Ask so
every write shows an approval card before it runs.
