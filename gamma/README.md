# Gamma

Make presentations and documents in Gamma, such as a media kit.

Connects through Gamma's own hosted MCP server at `https://mcp.gamma.app/mcp`.
Connecting opens Gamma's sign-in; the bots app registers itself with Gamma on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to mcp.gamma.app.

## Writes

This connector can change things in Gamma. Keep the workspace's approval mode on Ask so
every write shows an approval card before it runs.
