# Semrush

Keyword research, rankings, backlinks and competitor traffic from Semrush.

Connects through Semrush's own hosted MCP server at `https://mcp.semrush.com/v2/mcp`.
Connecting opens Semrush's sign-in; the bots app registers itself with Semrush on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to mcp.semrush.com.

## Read only

Research and reporting only; nothing in Semrush changes.
