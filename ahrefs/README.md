# Ahrefs

Keywords, backlinks, rankings and site health from Ahrefs.

Connects through Ahrefs's own hosted MCP server at `https://api.ahrefs.com/mcp/mcp`.
Connecting opens Ahrefs's sign-in; the bots app registers itself with Ahrefs on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to api.ahrefs.com.

## Read only

Research and reporting only; nothing in Ahrefs changes.
