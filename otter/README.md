# Otter

Meeting history and transcripts from Otter.

Connects through Otter's own hosted MCP server at `https://mcp.otter.ai/mcp`.
Connecting opens Otter's sign-in; the bots app registers itself with Otter on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to mcp.otter.ai.

## Read only

Research and reporting only; nothing in Otter changes.
