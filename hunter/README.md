# Hunter

Find and verify contact emails for brand partnership pitches.

Connects through Hunter's own hosted MCP server at `https://mcp.hunter.io/mcp`.
Connecting opens Hunter's sign-in; the bots app registers itself with Hunter on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to mcp.hunter.io.

## Read only

Research and reporting only; nothing in Hunter changes.
