# Fathom

Meeting recordings, summaries and action items from Fathom.

Connects through Fathom's own hosted MCP server at `https://api.fathom.ai/mcp`.
Connecting opens Fathom's sign-in; the bots app registers itself with Fathom on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to api.fathom.ai.

## Read only

Research and reporting only; nothing in Fathom changes.
