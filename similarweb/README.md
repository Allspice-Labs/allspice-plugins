# Similarweb

Traffic estimates and audience comparisons for any site.

Connects through Similarweb's own hosted MCP server at `https://mcp.similarweb.com`.
Connecting opens Similarweb's sign-in; the bots app registers itself with Similarweb on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to mcp.similarweb.com.

## Read only

Research and reporting only; nothing in Similarweb changes.
