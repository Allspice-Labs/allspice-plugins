# TikTok for Business

TikTok ad campaigns, audiences and reports.

Connects through TikTok for Business's own hosted MCP server at `https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer`.
Connecting opens TikTok for Business's sign-in; the bots app registers itself with TikTok for Business on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to business-api.tiktok.com.

## Writes

This connector can change things in TikTok for Business. Keep the workspace's approval mode on Ask so
every write shows an approval card before it runs.
