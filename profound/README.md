# Profound

How often AI answers mention and cite the site, from Profound.

Connects through Profound's own hosted MCP server at `https://mcp.tryprofound.com/mcp`.
Connecting opens Profound's sign-in; the bots app registers itself with Profound on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to mcp.tryprofound.com.
