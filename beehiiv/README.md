# beehiiv

Newsletter posts, subscribers and tags in beehiiv.

Connects through beehiiv's own hosted MCP server at `https://mcp.beehiiv.com/mcp`.
Connecting opens beehiiv's sign-in; the bots app registers itself with beehiiv on the first
connection, so there are no keys to paste. Tokens stay encrypted in the bots app and calls go
straight to mcp.beehiiv.com.

## Writes

This connector can change things in beehiiv. Keep the workspace's approval mode on Ask so
every write shows an approval card before it runs.
